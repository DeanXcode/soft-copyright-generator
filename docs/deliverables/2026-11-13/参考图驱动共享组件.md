# 参考图驱动共享组件

日期：2026-11-13

已按“API 参考图 → 视觉样式契约 → 代码组件 → 页面截图”的路线补齐普通 React/PageSpec 路径。参考图仍由现有图片 API 生成；本轮没有新增 Figma 依赖，没有修改 API 配置。

## 已实现

- 每张参考图做一次逻辑视觉分析，提取主色、正文色、工作区、表面、边框、导航及导航文字颜色，以及卡片/控件圆角、紧凑度和阴影。
- 结果经过白名单、范围和对比度校验；本地代码生成样式并复用于导航、卡片、表格、表单、按钮、登录页和共享确认框。模型不提供任意 CSS/JS。
- 以真实图片内容哈希和契约版本缓存到生成工程的 `react-app/reference-component-style.json`。续跑复用；换图可重用已有 PageSpec 本地重渲染，不需要重新请求页面内容，截图指纹随样式变化更新。
- 视觉分析失败自动沿用原组件样式，不阻断页面生成。失败决定同样缓存，避免续跑重复等待；需要重试时删除该缓存文件或更换图片。没有图片时零视觉请求。
- 此分析关闭网络重试，provider 仍可能执行响应格式等兼容回退；60 秒是读取超时设置，不是阶段总耗时保证。原直接看图生成 React 的专用路径不额外叠加这一步。

## 范围与遗留事项

本轮复用已有参考图及 PageSpec，没有新生图片、没有新请求页面、没有跑完整材料生成，也没有制作安装器。API 新任务增加一次视觉分析开销，不能据本轮结果宣称整单提速或成功率提升；历史首次整单成功率仍为 1/3，恢复结果单列。

当前提取的是视觉样式，整体布局、导航拓扑和业务结构仍由代码规则及 PageSpec 决定，不是参考图的像素级还原。工作区仍限制为浅色。行业组件形态、布局差异和原有内容一致性/版面风险尚未在本轮解决。默认模板零 Token、Headless Shell 默认及 API 配置保持原行为。
