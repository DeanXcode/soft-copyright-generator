## 根因与本地修复

1. **医疗说明书登录字段识别不全。** 实际登录字段为“医护账号”和“密码”，旧固定候选词遗漏“医护账号”，说明书只引用密码，触发语义覆盖校验。现在优先从真实截图元数据提取账号、账户、手机号、邮箱、工号、密码、验证码等字段，过滤帮助文本、验证码值及“记住账号”等控制项，并统一用于图注、登录导语和操作步骤。保留原图文一致性门禁；增加医疗、教育、企业邮箱三种字段回归场景。图文一致性分析结果新增写入 `manual-ui-consistency.json`，失败时也能复核失配细节。
2. **内嵌 Python 的生成项目测试导入失败。** 原测试在开发环境 364/364 通过，但内嵌环境仅 363/364。生成项目的持久化测试现在显式加入项目根路径；回归用 `python -I` 隔离模式运行子进程，覆盖开发与交付运行时的路径差异。
3. **教育图片上游超时仍未解决。** 已确认是图片请求连续返回 HTTP 524，而非本轮观察到的文本鉴权失败；具体上游责任仍需诊断。现有四次请求未能恢复，继续盲目加重试会拉长等待。未修改网关、密钥、图片渠道或正式生成兜底策略，也未通过跳过参考图宣称成功。
